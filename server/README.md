# Backend (Server)

This folder will contain the backend server for Critiq.

## Planned Responsibilites
- Handle API requests from the frontend
- Manage data (reviews, users, etc.)
- Perform validation and error handling

## Planned Endpoints
- GET /help - check server status
- GET /api/example - test endpoint
- POST /api/reviews - submit a review (future)

## Notes
- Backend will run as a seperate Node.js server
- Intended port: 5000
